# Captures du laboratoire de falaises

Sept vues produites avec `npm run test:cliffs` sous Chromium/SwiftShader.
Le rapport `views-report.json` contient les triangles et draw calls de la scène entière,
ainsi que les triangles résidents et la répartition LOD des seules falaises.

Voir [le guide du laboratoire](../../53-CLIFF-REFERENCE.md) pour ouvrir, modifier,
exporter et reproduire la scène. La série ajoute une vue des décrochements aux six
vues minimales demandées. Aucun FPS n'est qualifié par ces captures logicielles.
