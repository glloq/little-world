# Déplacements dynamiques

Captures et rapport du contrôle de production, par vrais événements clavier/souris
via Playwright. `report.json` contient les positions, vitesses, assiettes, ticks, FOV et
compteurs de rendu aux étapes roulade, déploiement, piqué, cabré et virage.

`physics-bench.json` mesure uniquement le CPU sous Node. Les captures SwiftShader
prouvent le fonctionnement, sans qualifier le ressenti ni les performances GPU.

Voir [le guide](../../54-DYNAMIC-MOVEMENT.md) pour reproduire la scène et les contrôles.
